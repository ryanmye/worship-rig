`worship-rig-starter-library.json` is a Worship Rig library backup holding the 19 factory songs and the first setlist, written by the app's own Export library.
To load it, open Settings › Library & backups › Import… and pick the file; the songs are added next to the ones you already have.
It is the factory library as of v0.1.0, exported from a fresh profile of the built Mac app.
