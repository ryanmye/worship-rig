# Contributing to Worship Rig

Thanks for wanting to help. Bug reports, sound and song suggestions and pull requests are welcome on GitHub
(https://github.com/ryanmye/worship-rig).

If you can't agree to point 3, say so in the pull request before it is merged; it won't be merged without it.

Third-party code must come with a licence that allows distributing it inside a PolyForm Noncommercial program
(for example MIT, BSD, Apache-2.0, zlib, public domain / CC0). GPL, LGPL and AGPL code can't be accepted. Samples
and fonts follow `LICENSES.md`: they keep their own licences and need their attribution recorded there.

## Practical notes

- Read `CLAUDE.md` (conventions, module boundaries, how to run the tests) and `docs/architecture.md` first.
- Run `npm test` (or `node test/run-all.mjs --fast`) before opening a pull request.
- Never commit GarageBand/Logic conversions, My Samples, patch packs or sound-pack audio (see `CLAUDE.md`).
