## Fixes made (owned files)

- `src/mix/master_chain.cpp`: the pending glue disconnect (fx.js `timer.at(when + 0.04)`) used to be stored as a frame
  index at the rate in force when the op arrived. After a sample-rate change, `ctx.frame0` is on the new grid, so a
  48 kHz to 96 kHz switch would detach about 20 ms early. That freezes the compressor state at the wrong moment, and
  a later re-engage starts from that state. The fix stores the time in seconds and quantises it at the current rate in
  `process()` (`timerFrame`). At a constant rate the result is identical (fixtures and the JS ports re-run green).
- `src/mix/master_chain.cpp` `setGlue`, `src/mix/master_chain_tables.cpp` `glueSettings`: `Number(a) || 0` keeps
  `±Infinity`, which then clamps to 1 or 0. The old code mapped `+Infinity` to 0. The new code maps only NaN to 0.
  Bridge values are already clamped, so this is parity only.
- Lines over 120 characters: `src/mix/master_chain_tables.h:7`, `tests/test_master_dsp.cpp:189`, and
  `tools/golden/vectors/dump-compressor.mjs:102,112`.

## Real-time safety (read)

- No allocation, lock or I/O in `process`/`apply`. The tables (`compMakeup`, `glueRefTable`, `clipCurve`) are function
  statics, first touched in the MasterChain constructor on the control thread. The resampler vectors and WaveShaper
  kernels are allocated in the constructors.
- Bounded loops: `kAtSlope` runs 15 iterations, only when threshold, knee or ratio change (each quantum during a
  threshold `rampTo`, as in Chromium). The 32-frame divisions are bounded.
- Denormals: the compressor state is flushed at the end of each division, as `DenormalDisabler` does. `rt_guard`
  sets FTZ/DAZ on the audio thread. The FIR resamplers have no feedback.
- Buffers: the pre-delay index is masked to 1024 and the delay is clamped to 1023 frames (above 170 kHz). The
  convolution history sizes check out: up `127 + n`, down `127 + n/2`, max read index `n + 126`.
