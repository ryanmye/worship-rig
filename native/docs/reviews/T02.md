# T02 filters & strip (extend): skeptic review

Reviewer build dirs: `native/core/build-t02-review` (g++ 13 Release), `build-t02-review-clang` (clang 18 Release),
`build-t02-review-asan` (g++ ASan+UBSan). Renders by `rig_render`, compared with `tools/golden/compare.mjs`
(exact tier, maxAbsDiff 2e-4).

## Verdict

The builder's claims hold. Every T02 fixture renders bit-exact (max |diff| 0) on g++ and clang. The one exception is
`eq-type-change`, and its committed golden is the faulty one: the corrected JS render matches native exactly. Two
adversarial scratch fixtures, written for this review, are also bit-exact on both compilers. Five small defects were
fixed in T02's own files (four in the first pass, one in the resume pass below). Nothing needs a larger change in
T02. The open items below are hand-offs.

## Fixes made in this review (T02-owned files)

1. **Lost SlotEq timers** (`src/mix/slot_eq.{h,cpp}`).
   - The cause: `kTimers` was 16. When the table was full, `at()` overwrote the last timer.
   - How it is reached: a switch in progress plus a peak↔shelf change on all 8 bands makes 17 live timers (1 switch
     plus 8 fades on each chain).
   - The effect: the lost callback left a node stuck mid-fade at 0 dB, or a switch never finished.
   - The fix: the table is now 32. When it is full, `at()` reuses a stale timer (a superseded seq, or a dead or
     dropped node). Test: `unit.strip` "SlotEq timers: 16 type fades during a chain switch (17 live timers)".
2. **Leaked SetEq payloads** (`src/mix/slot_channel.cpp`).
   - The cause: `setEqRow` sends one Store payload per row write, so a burst of more than 16 EQ rows in one quantum
     overflowed `pending_[16]`. The extra payloads were never handed back.
   - The fix: `kPending` is now 128 (43 EQ rows per slot). `~SlotChannel` deletes payloads that are still pending.
     Units are deleted on the control thread.
3. **First static init on the audio thread** (`src/mix/slot_channel.cpp`). `defaultSlotEqSpec()`'s function-local
   static could be built for the first time inside `apply()` on the audio thread, on the first audition, which takes
   a guard acquire. `makeSlotChannel` (control thread) now builds it.
4. **NaN delay time could index out of bounds** (`src/dsp/delay_line.cpp`).
   - The cause: `std::max(NaN, 0.f)` and `std::clamp(NaN, …)` return NaN, and a NaN cast to an index is undefined
     behaviour (an out-of-bounds read).
   - The fix: `x > 0 ? x : 0`, which is bit-identical for every number.
   - The sample form `read()` takes the owner's raw double, so it was reachable from T05/T04 code. The block form only
     gets values from its Param, which already rejects NaN, so that guard is defensive.
   - Test: `unit.delay_line` "a NaN delay time reads as 0".

After the fixes: g++ and clang ctest 43/45 each, with the same two failures as before, both owned by others (below).
`golden.eq`, `golden.t02`, `golden.master`, `golden.reverb`, `golden.t05` and `golden.click` pass. The T02 suites:
`unit.strip` (10 cases), `unit.biquad`, `unit.panner` and `unit.delay_line` (2 cases) pass.

## Resume pass (after the container restart)

All results below were re-measured on the current tree, after the other agents' changes.

- **Builds.** g++, clang and ASan+UBSan all build. `tests/test_rec.cpp` now compiles under ASan, so the first pass's
  link workaround is no longer needed.
- **ctest, g++ and clang.** 43/45 each. The only failures are `unit.clock` (T03, item 5) and `unit.golden-analytic`
  (T07, item 6: `test_golden.cpp:116-117`, the click now peaks at 0.5).
- **ctest, ASan+UBSan (`-fno-sanitize-recover=all`).** 43/45, with the same two failures and no sanitizer reports.
  `golden.eq`, `golden.t02`, `golden.master`, `golden.reverb`, `golden.t05` and `golden.click` pass, and so do the
  T02 suites.
- **JS suite.** `node test/run-all.mjs --only unit`: 502 pass, 0 fail, 9 skip.
- **Renders.** Every fixture in the table above was re-rendered on both compilers, and every one still has a max
  |diff| of 0.
  - `eq-type-change` is 4.17e-1 against the committed golden. It is 0 against a JS render made in scratch with the
    fixed `page.js`.
- **Fixtures that discriminate.**
  - width-0 vs width-50 differ by up to 0.12, and width-50 vs width-150 by up to 0.26.
  - width-0 is mono (L−R ≤ 1.5e-8), while width-50 has L−R up to 0.25.
  - pan-stereo-src has L−R up to 0.49.
  - The 18 `eq-*` impulse goldens peak between 0.08 and 1.06.
- **Fix 5 (`src/mix/slot_eq.cpp`).** `butter2Q()` held a function-local static with a dynamic initialiser
  (`js::log10`). It is called from `eqSpec()`/`buildEqChain()` on the audio thread, for example the first time a
  low or high cut is engaged, which takes the init guard there. It is now computed on each call, with the same
  value. All T02 goldens and suites still pass on both compilers.
