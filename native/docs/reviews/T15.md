# T15 synth-extra + organ: skeptic review

Verdict: **PARTIAL**. Everything the builder measured reproduces. The parity claims hold (19/19 fixtures, 18 at the
exact tier, clang 20 renders byte-identical, O2 correct against the Chromium source). Two small defects were fixed in
review (below). Two live-engine gaps remain that no fixture exercises: the organ rotary enum and the organ morph or
release never reach the organ, and drawbar changes are dropped. Both need files T15 does not own.

Build dirs: `native/core/build-t15-review` (g++ 13 Release), `-clang` (clang++-20 `-Werror`), `-asan` (g++
ASan+UBSan). Renders were made with `rig_render` and compared with `tools/golden/compare.mjs`.

- Real-time safety:
  - No allocation, lock or unbounded loop on the audio path. Every buffer (chorus and horn delay lines, the PWM

    `XWaveBank::get` mutex is control-thread only.
  - XDelay reads are clamped to `[0, maxDelay]`, so it cannot overrun.
  - Fixed tables are bounded at compile time: supersaw uses 8 sources and 8 tracked params, against limits of 8 and
    10.

## Fixed in review (owned files)

1. **Organ `_syncOversample` was missing** (medium). organ.js switches its tanh shaper between `'none'` and `'2x'`
   when `drive` crosses 0.5, but only while `alloc.size === 0`. It does this at a drive `setParam` and at every
   voice build. Native fixed the oversampling at construction.
   - New vector `soft-drive-switch` in `dump-organ.mjs` / `data/organ.txt`: drive 0.9 set while idle on soft-pad,
     then a chord. The unfixed build gives max\|diff\| **0.398** (peak 0.248). After the fix it is 2.89e-6.
   - Fix (`organ.{h,cpp}`): both shapers (None and X2) are built on the control thread. `syncOversample()`
     re-points the active one when `pool_.live() == 0`.
2. **Numeric bool params were clamped instead of `>= 0.5`** (low). `XHost::setParam` turned organ `percussion = 0.3`
   into 0.3, which `!= 0` reads as on. JS `coerceParam` gives false.
   - Fix (`synth_extra_host.h`): `v = value >= 0.5 ? 1 : 0` for `unit == "bool"`.
   - Test: `unit.organ` gets 0.3 → 0 and 0.7 → 1.

## Open items (need files T15 does not own)

1. **HIGH: organ `rotary` set from the UI always becomes `slow`** (`src/model/model.cpp`, T13 / orchestrator).
   - The Edit view sends enum params as strings (`slots.<i>.params.rotary = 'fast'`, `views/edit/panels/slot.js`
     `C.select`). `Model::set`'s dynamic branch converts only numbers and bools to `v`, so a string arrives as 0
     (slow), and `withParam` stores 0 in `paramsJson`.
   - Change: in the dynamic branch, add
     `else if (mv && yyjson_is_str(mv)) v = inst::instEnumIndex(active_.slots[slot], key, yyjson_get_str(mv));`
   - For the helper, T15 can add `int instEnumIndex(const SlotPatch &, std::string_view key, std::string_view s)` in
     `inst/organ.h`. It returns `rotaryEnum` for organ and −1 otherwise. On −1 the request is
     dropped, which matches JS: an invalid enum falls back to the default.
2. **HIGH: organ morph (the Leslie half-moon switch, `macro.intensity`) and `slots.<i>.release` never reach an organ**
   (`src/model/song.cpp`, T13 / T14).
   - `SongGraph::sendRelease`, `applyFresh` and the reuse path (lines ~340, ~364, ~432) send only
     `SynthOp` / `SamplerOp`.
   - Change: in all three places, add
     `else if (c.kind == inst::kKindOrgan) cmd.op = opOf(inst::OrganOp::Morph);`
     with `OrganOp::ReleaseOverride` in `sendRelease`, and `#include "inst/organ.h"`.
   - synth-extra is unaffected: it is `inst.synth`.
3. **MEDIUM: drawbar changes are stored but never heard** (`organ.cpp` `applyParam` key < 9).
   - organ.js `_scheduleWave` rebuilds the 8 drawbar PeriodicWaves (30 ms debounce) and re-points every live voice.
     Native cannot build PeriodicWaves on the audio thread, and there is no control-side param hook: T11's
     `slots.<i>.params.` handler owns the row, and `services.h` is frozen.
   - Change: in `setInstrumentParam` (T11 `instrument_service.cpp`), when `kind == inst.organ` and the key is
     `drawbar*`, call a T15 hook `organDrawbarsChanged(Model&, slot)`. The hook would debounce 30 ms on the control
     thread, run `drawbarWaves(organParams(paramsJson))`, and send `T15Op::SetTables` with only `drawbars` set.
   - The unit side already swaps `drawbars` and re-points voices. It needs a variant that keeps `bank_` / `xbank_`
     when `w->bank` is null. That is about 10 lines in `organ.cpp`, and T15 can do it once the hook exists.
   - Each rebuild costs 4.7 MB and about 50 ms of control-thread work.
4. **LOW: rate change leaves T15 DelayNodes at the old rate.** `XDelay::sr_` is fixed at `attach`, so after a device
   rate change the synth-extra chorus (juno, dx) and the organ horn delay run at `old/new` × their delay time
   (44.1 → 48 kHz: 3.5 ms becomes 3.2 ms). The `t15-tables` service re-points only the oscillators. It is
   bounds-safe: the buffer length and max are unchanged. Fix in T15 files: on `T15Op::SetTables`, re-`attach` the
   shared delay lines at the payload's rate, or carry a rate field.
5. **LOW: T11 O5 is not fully closed.** `pendingEnded_` has 32 entries, but every note-on into a pool full of fading
   voices evicts one. So more than 32 such note-ons in one quantum overflow it. T15's host counts those drops. T11's
   `synth.cpp` drops them silently, and its comment "none dropped" is wrong. Either size the table to
   `kVoicePoolSize + kVoiceSpare`, or emit at eviction time.
6. **NOTE: `synth-dx-epiano` margin.** Its bands are 2.90 dB against a 2.99 dB limit, and 2.39 dB is Chromium's own
   seed spread. Any change to the FM table set (8 steps of 0.04 rad, versus JS's 0.002 rad quantum) can tip it.
   It is deterministic, so it is not flaky. It is Q11-allowed.
7. **NOTE: idle organ cost.** 18–37 µs per idle organ instrument, from the always-running rotary. JS behaves the
   same, so there is no parity issue. An idle skip of the rotary (no voices, tail below the denormal floor) would cut
   it, but it changes output after the tail, so it needs an orchestrator decision.
8. **D4 Auto** with supersaw at 12 µs: ≈ 122 voices (orchestrator decision; the builder left 128).
